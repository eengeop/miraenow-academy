# MiraeNow Academy

학부모가 휴대폰에서 안내장을 읽기 위한 웹뷰어 프로젝트입니다. 현재는 실제 학생 정보와 실제 안내장을 사용하지 않습니다.

## 개발 순서

1. 샘플 긴 이미지의 모바일 읽기·확대 경험을 검증합니다.
2. 서버가 보관하는 안내장을 충분히 무작위인 링크로만 제공합니다. 링크 폐기·재발급과 접근 기록 최소화를 구현합니다.
3. 모바일 웹에서 PDF 페이지를 읽을 수 있게 합니다.
4. 반복 업로드가 필요할 때 관리 화면을 추가합니다.

학원 소개, 로그인, 결제, 학생 정보 관리는 현재 범위에 없습니다. 공개 포트폴리오에는 샘플 자료만 사용합니다.

## 로컬 실행

Node.js 24 이상이 필요합니다. 처음 한 번 의존성을 설치합니다.

```sh
npm ci
```

```sh
npm run dev
```

`http://localhost:3000`에서 샘플을 볼 수 있습니다. Windows PowerShell에서 `npm` 실행이 차단되면 `npm.cmd run dev`를 사용합니다.

```sh
npm run check
```

`check`는 공개 데모를 `dist/`에 빌드하고 HTTP 동작 테스트를 실행합니다. `dist/`는 공개 데모 전용입니다. 링크로 제공하는 샘플 이미지는 `samples/`에서 서버가 읽으며 `dist/`에 복사하지 않습니다.

## 샘플 링크 발급과 폐기

서버를 실행한 상태에서 별도 터미널로 다음 명령을 실행합니다.

```sh
npm run links -- issue sample-a
npm run links -- issue sample-b
npm run links -- issue sample-pdf
npm run links -- revoke sample-a
```

`issue`는 새 URL을 한 번 출력합니다. 같은 샘플에 다시 발급하면 이전 링크는 즉시 무효가 됩니다. `revoke`는 현재 링크를 폐기합니다. 링크 정보는 Git에서 제외한 `private/links.json`에 보관하며 **원본 토큰 대신 SHA-256 해시**만 저장합니다. 배포 주소를 출력하려면 `BASE_URL` 환경 변수를 설정합니다. 명령 출력에 나타난 URL은 링크를 받을 사람에게만 전달하고 로그에 복사하지 않습니다.

링크를 가진 누구나 해당 안내장을 볼 수 있습니다. 현재 구현은 두 샘플 이미지와 샘플 PDF의 로컬 검증용이며 실제 학생 자료나 운영용 업로드·관리 기능은 없습니다. 공개 데모 `/`와 `/sample-notice.svg`는 화면 검증용으로만 유지합니다.

PDF 샘플 링크는 2페이지짜리 가상 문서를 브라우저 안에서 렌더링합니다. PDF.js 라이브러리와 worker를 같은 서버에서 제공하므로 별도 PDF 앱이나 외부 CDN 요청이 필요하지 않습니다. 샘플은 코드로 생성하며 실제 학생 정보가 없습니다. 모바일 브라우저 동작은 별도로 확인해야 합니다.

## 개발 원칙

작은 기능 브랜치와 PR로 진행합니다. 각 PR은 화면 캡처, 실행한 검증, 남은 작업을 기록합니다. 실행 방법과 설계 결정은 이 문서와 `docs/`에 갱신합니다.

현재 완료 기준과 남은 검증은 [품질 기록](docs/quality.md)에 적습니다.
