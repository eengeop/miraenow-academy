# MiraeNow Academy

학부모가 휴대폰에서 안내장을 읽기 위한 웹뷰어 프로젝트입니다. 저장소와 공개 데모에는 실제 학생 정보와 실제 안내장을 넣지 않습니다.

## 개발 순서

1. 샘플 긴 이미지의 모바일 읽기·확대 경험을 검증합니다.
2. 서버가 보관하는 안내장을 충분히 무작위인 링크로만 제공합니다. 링크 폐기·재발급과 접근 기록 최소화를 구현합니다.
3. 모바일 웹에서 PDF 페이지를 읽을 수 있게 합니다.
4. 반복 업로드가 필요할 때 관리 화면을 추가합니다.

학원 소개, 로그인, 결제, 학생 정보 관리는 현재 범위에 없습니다. 공개 포트폴리오에는 샘플 자료만 사용합니다.

실제 안내장에는 이름·학년 외에 점수와 교사 의견이 들어갈 수 있습니다. [데이터 운영 결정](docs/data-policy.md)의 접근·보관 기준을 확정하기 전에는 실제 자료를 로컬에서만 시험합니다.

## 로컬 실행

Node.js 24 이상이 필요합니다. 처음 한 번 의존성을 설치합니다.

```sh
npm ci
```

```sh
npm run dev
```

`http://127.0.0.1:3000`에서 샘플을 볼 수 있습니다. 서버는 기본적으로 이 컴퓨터에서만 접속할 수 있습니다. Windows PowerShell에서 `npm` 실행이 차단되면 `npm.cmd run dev`를 사용합니다.

```sh
npm run check
```

`check`는 공개 데모를 `dist/`에 빌드하고 HTTP 동작 테스트를 실행합니다. `dist/`는 공개 데모 전용입니다. 링크로 제공하는 샘플 이미지는 `samples/`에서 서버가 읽으며 `dist/`에 복사하지 않습니다.

## 샘플 링크 발급과 폐기

서버를 실행한 상태에서 별도 터미널로 다음 명령을 실행합니다.

```sh
npm run links -- issue sample-a
npm run links -- issue sample-b
npm run links -- issue sample-pdf
npm run links -- revoke sample-a
```

`issue`는 새 URL을 한 번 출력합니다. 링크는 발급 후 30일에 만료합니다. 같은 샘플에 다시 발급하면 이전 링크는 즉시 무효가 됩니다. `revoke`는 현재 링크를 폐기합니다. 링크 정보는 Git에서 제외한 `private/links.json`에 보관하며 **원본 토큰 대신 SHA-256 해시**만 저장합니다. 만료 시각이 없는 이전 버전 링크는 더 이상 열리지 않으므로 새로 발급해야 합니다. 배포 주소를 출력하려면 `BASE_URL` 환경 변수를 설정합니다. 명령 출력에 나타난 URL은 링크를 받을 사람에게만 전달하고 로그에 복사하지 않습니다.

링크를 가진 누구나 해당 안내장을 볼 수 있습니다. 현재 구현은 두 샘플 이미지, 샘플 PDF와 로컬 PNG 한 장의 검증용이며 운영용 업로드·관리 기능은 없습니다. 공개 데모 `/`와 `/sample-notice.svg`는 화면 검증용으로만 유지합니다.

PDF 샘플 링크는 2페이지짜리 가상 문서를 브라우저 안에서 렌더링합니다. PDF.js 라이브러리와 worker를 같은 서버에서 제공하므로 별도 PDF 앱이나 외부 CDN 요청이 필요하지 않습니다. 샘플은 코드로 생성하며 실제 학생 정보가 없습니다. 모바일 브라우저 동작은 별도로 확인해야 합니다.

유효한 링크의 화면에는 파일 저장 버튼이 있습니다. 이미지와 PDF는 각각 원본 형식으로 내려받으며, 폐기되거나 만료된 링크에서는 다운로드도 차단됩니다. 저장된 파일은 받는 사람의 기기에 남으므로 링크 폐기로 이미 내려받은 사본을 지울 수는 없습니다.

## 로컬 PNG 파일 테스트

`uploads/testImage2.png`를 넣고 서버를 실행합니다. `uploads/`는 Git에서 제외하며 공개 정적 빌드에도 들어가지 않습니다. 파일명과 캡처에는 학생 이름을 넣지 않습니다. 별도 터미널에서 다음 명령으로 링크를 발급합니다.

```sh
npm run links -- issue local-image
```

출력된 주소를 이 컴퓨터의 브라우저에서 열면 긴 PNG를 화면 폭에 맞춰 읽고 확대할 수 있습니다. 테스트 후 다음 명령으로 링크를 폐기합니다.

```sh
npm run links -- revoke local-image
```

기본 서버는 `127.0.0.1`에만 연결되므로 휴대폰에서 직접 열려면 별도의 접속 설정이 필요합니다. 개인정보가 있는 파일을 공개 배포하거나 PR에 첨부하기 전에 접근·보관 정책을 검토해야 합니다.

## 개발 원칙

작은 기능 브랜치와 PR로 진행합니다. 각 PR은 화면 캡처, 실행한 검증, 남은 작업을 기록합니다. 실행 방법과 설계 결정은 이 문서와 `docs/`에 갱신합니다.

현재 완료 기준과 남은 검증은 [품질 기록](docs/quality.md)에 적습니다.
