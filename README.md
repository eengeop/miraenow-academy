# MiraeNow Academy

학부모가 휴대폰에서 안내장을 읽기 위한 웹뷰어 프로젝트입니다. 현재는 실제 학생 정보와 실제 안내장을 사용하지 않습니다.

## 개발 순서

1. 샘플 긴 이미지의 모바일 읽기·확대 경험을 검증합니다.
2. 서버가 보관하는 안내장을 충분히 무작위인 링크로만 제공합니다. 링크 폐기·재발급과 접근 기록 최소화를 구현합니다.
3. 모바일 웹에서 PDF 페이지를 읽을 수 있게 합니다.
4. 반복 업로드가 필요할 때 관리 화면을 추가합니다.

학원 소개, 로그인, 결제, 학생 정보 관리는 현재 범위에 없습니다. 공개 포트폴리오에는 샘플 자료만 사용합니다.

## 개발 원칙

작은 기능 브랜치와 PR로 진행합니다. 각 PR은 화면 캡처, 실행한 검증, 남은 작업을 기록합니다. 실행 방법과 설계 결정은 이 문서와 `docs/`에 갱신합니다.
