# 실제 안내장 데이터 운영 결정

이 문서는 배포 전 설계 결정을 기록한다. 현재 구현은 로컬 검증용이며 실제 안내장을 인터넷에 공개 제공하지 않는다.

## 자료 범위

- 실제 안내장에는 학생 이름, 학년, 점수, 교사 의견이 포함될 수 있다.
- 포트폴리오, 공개 저장소, PR, 이슈, 화면 캡처에는 실제 학생 자료를 사용하지 않는다. 시연에는 가상 자료만 사용한다.
- 이 범위 밖의 정보가 필요해지면 자료 항목과 접근·보관 기준을 다시 검토한다.

## 현재 접근 방식과 남은 결정

| 항목 | 현재 상태 | 운영 전 결정 |
| --- | --- | --- |
| 열람 | 256비트 무작위 링크를 가진 사람은 열람·다운로드 가능. 발급 후 30일 만료, 폐기·재발급 지원. 회원 기능은 추후 단계 | 전달 대상과 오발송·전달 시 대응 |
| 원본 | 로컬 `uploads/`에만 보관하며 Git과 공개 빌드에서 제외. 운영 시 30일 보관 결정 | 비공개 저장소, 30일 기산점, 자동 파기 범위와 절차 |
| 백업 | 운영 백업 없음 | 백업 필요 여부와 보유·파기 기준 |
| 배포 | 기본 서버는 `127.0.0.1`에만 연결 | HTTPS, 요청 URL·토큰이 기록되지 않는 설정, 운영자 권한 |

보유기간이 지나거나 처리 목적이 끝나 불필요해진 개인정보의 파기, 안전조치, 처리 목적과 보유기간을 포함한 처리방침을 운영 단계에서 검토한다. 참고: [개인정보 보호법 제21조](https://law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1029334977), [제29조](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900079357), [제30조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1006185717).

다운로드 받은 사본은 받는 사람의 기기에 남는다. 링크 폐기나 서버 원본 파기는 이미 내려받은 사본을 회수하지 못한다.
