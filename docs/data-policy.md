# 실제 안내장 데이터 운영 결정

이 문서는 실제 자료의 외부 제공 전 설계 결정을 기록한다. Cloudflare에는 가상 자료만 배포했다. 실제 안내장은 로컬에서만 검증하며 인터넷에 제공하지 않는다.

## 자료 범위

- 실제 안내장에는 학생 이름, 학년, 점수, 교사 의견이 포함될 수 있다.
- 포트폴리오, 공개 저장소, PR, 이슈, 화면 캡처에는 실제 학생 자료를 사용하지 않는다. 시연에는 가상 자료만 사용한다.
- 이 범위 밖의 정보가 필요해지면 자료 항목과 접근·보관 기준을 다시 검토한다.

## 현재 접근 방식과 남은 결정

| 항목 | 현재 상태 | 운영 전 결정 |
| --- | --- | --- |
| 열람 | 256비트 무작위 링크를 가진 사람은 열람·다운로드 가능. 발급 후 30일 만료, 폐기·재발급 지원. 회원 기능은 추후 단계 | 전달 대상 확인과 오발송 대응 절차 확정 |
| 원본 | 로컬 `uploads/` 사용자 원본은 자동 삭제하지 않음. 로컬 앱 복사본과 Cloudflare 가상 R2 복사본은 등록일부터 30일 후 열람 차단·정리 | 운영자가 원본을 직접 삭제하기로 함. 삭제 시점은 미정 |
| 백업 | 운영자가 실제 안내장 파일의 별도 백업을 만들지 않기로 함 | Cloudflare 기본 복구 이력과 삭제 범위를 확인하고 운영 방식에 반영 |
| 배포 | 로컬 서버는 `127.0.0.1`에 연결. Cloudflare의 HTTPS 데모에는 가상 자료만 있음 | 운영자 접근 범위, 요청 URL·토큰의 로그 및 분석 도구 노출, 접근·파기 확인 방법 |

## 오발송과 운영자 접근 제안

- 오발송을 알게 되면 해당 링크를 즉시 폐기하고, 올바른 수신자를 다시 확인한 뒤 새 링크를 발급한다. 잘못 받은 사람이 이미 열람하거나 다운로드한 사본은 링크 폐기로 회수할 수 없으므로 그 사실과 후속 연락 여부를 운영자가 확인한다. 실제 운영 전에는 원격 D1에서 링크를 빠르게 폐기·재발급할 수 있는 운영 명령을 검증해야 한다.
- 운영자는 우선 계정 소유자 한 명만 Cloudflare Worker·D1·R2를 관리하고 추가 멤버나 공유 API 토큰을 만들지 않는 방안을 제안한다. 이는 현재 계정의 실제 멤버·권한을 확인한 결과가 아니다. 운영 전 Cloudflare 멤버 목록과 로그인된 기기, API 토큰을 확인한다. 추가 담당자가 필요해지면 필요한 자원에만 권한을 부여한다. [Cloudflare 멤버·역할 안내](https://developers.cloudflare.com/fundamentals/manage-members/)

## 백업에 관한 제공자 동작

별도 파일 백업을 만들지 않더라도 Cloudflare D1의 Time Travel 복구 이력은 기본으로 활성화되어 있으며 Workers Free에서 최대 7일 전으로 복원할 수 있다. D1에는 안내장 파일 자체나 원본 링크 토큰을 저장하지 않고, 객체 키·형식·만료 시각과 토큰 해시를 저장한다. R2 파일은 앱의 30일 정리 대상이며, 제공자 내부 보존·로그의 상세 범위는 실제 자료를 올리기 전에 확인한다. [Cloudflare D1 Time Travel 안내](https://developers.cloudflare.com/d1/reference/time-travel/)

보유기간이 지나거나 처리 목적이 끝나 불필요해진 개인정보의 파기, 안전조치, 처리 목적과 보유기간을 포함한 처리방침을 운영 단계에서 검토한다. 참고: [개인정보 보호법 제21조](https://law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1029334977), [제29조](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900079357), [제30조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1006185717).

다운로드 받은 사본은 받는 사람의 기기에 남는다. 링크 폐기나 서버 원본 파기는 이미 내려받은 사본을 회수하지 못한다.

링크 재발급은 관리 복사본의 만료일을 연장하지 않는다. 로컬 서버가 중단되었을 때는 다음 시작 시 만료 파일을 정리한다. Cloudflare 데모는 만료 즉시 열람을 차단하고 매시 예약 작업으로 R2 복사본과 D1 기록을 정리한다. 실제 예약 작업의 만료 후 결과는 아직 확인하지 않았다.
