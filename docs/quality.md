| 관리 복사본 | 30일 경계 차단·삭제와 재발급 만료 제한 테스트. Cloudflare 예약 작업을 매시 설정 | 실제 만료 후 R2·D1 정리 결과 확인 |

2026-11-14 사용자 보고: Cloudflare 가상 데모의 모바일 이용에 문제가 없었다. 기기·브라우저 정보와 화면 캡처는 받지 않았다. 위 기록은 사용자 확인과 자동 HTTP 검증을 구분한다.

기능을 추가할 때 관련 행의 완료 기준과 검증 결과를 갱신합니다. 브라우저 또는 배포 환경에서 검증할 수 없으면 그 한계를 PR에 적습니다.
